✅ **二、动手实践是核心（关键！）**  
- ✅ 每学一个概念（如 Flex 布局、事件委托、Promise），立刻写 CodePen 或 VS Code 小 demo

✅ **三、技术栈学习顺序建议（就业向）**  
1. **基石三件套**：HTML5（语义化标签、表单、无障碍） → CSS3（Flex/Grid、动画、BEM 命名） → JavaScript（ES6+、DOM/BOM、异步编程、模块化）  
2. **工程化入门**：Git + npm/yarn + webpack/vite 基础配置（不用深挖，但要会搭脚手架、打包、热更新）  
3. **主流框架选其一深入**：  
   - Vue（生态友好，国内岗位多，尤雨溪团队文档极佳）  
   - React（大厂/外企主流，需掌握 Hooks、状态管理、Next.js）  
   *👉 建议先掌握一个，再横向对比学习另一个*  
4. **加分项（按需拓展）**：TypeScript（强烈推荐）、Node.js（基础 HTTP/Express）、UI 库（Element Plus / Ant Design）、测试（Jest + RTL）
