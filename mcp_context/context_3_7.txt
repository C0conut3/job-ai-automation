### ✅ 一、系统性学习路径（推荐初学者按顺序走）
1. **HTML + CSS 基础**
   - 掌握语义化标签、盒模型、Flex/Grid 布局、响应式设计（媒体查询、viewport）
   - 📚 推荐：[MDN Web Docs（中文）](https://developer.mozilla.org/zh-CN/docs/Web)｜免费权威  
   - 🎥 免费课：Bilibili《尚硅谷HTML+CSS》《黑马程序员前端入门》

2. **JavaScript 核心**
   - 变量/作用域/闭包/原型链/ES6+（let/const、解构、箭头函数、Promise、async/await）、DOM/BOM 操作
   - 📚 推荐：《JavaScript高级程序设计（第4版）》（红宝书）｜《你不知道的JS》系列（进阶必读）

3. **前端工程化 & 框架**
   - ✅ 先学 **Git + npm/yarn + webpack/vite 基础**  
   - ✅ 再选一个主流框架深入：
     - **Vue 3**（中文生态好，上手快，企业需求大）→ 推荐官方文档 + [Vue Mastery](https://www.vuemastery.com/)（部分免费）
     - **React 18**（生态最庞大，大厂/外企主流）→ 官方文档 + [Beta React Docs](https://react.dev/)（全新交互式教程）

4. **进阶能力（提升竞争力）**
   - TypeScript（强烈建议在框架熟练后立即学）  
   - 状态管理（Pinia / Redux Toolkit）  
   - UI 组件库（Element Plus / Ant Design Vue / Mantine）  
   - 前端测试（Vitest + React Testing Library / Vue Test Utils）  
   - SSR/SSG（Nuxt / Next.js）  
   - 性能优化 & 安全基础（CSP、XSS 防范）

| 方式 | 说明 | 小贴士 |
|------|------|--------|
| 🧩 **边学边做项目** | 从 TodoList → 个人博客 → 电商前台 → 后台管理系统（如基于 Ant Design Pro） | GitHub 上开源项目可 fork + 改造，写 README 记录思考过程 |
